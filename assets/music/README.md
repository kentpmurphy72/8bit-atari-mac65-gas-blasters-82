# Gas Blasters '82 — Atari POKEY music v1

**Selected tracks (approved musical direction):**

- **Arcade Rock** — Title screen, 148 BPM in A minor, and potentially reused in gameplay. Demo: `GasBlasters82_Title_ArcadeRock_POKEY.xex`.
- **Funky Gas Attack** — The two opening cutscenes, 110 BPM in G-blues/funk. Demos: `GasBlasters82_MeetTheCrew_Funky_POKEY.xex` and `GasBlasters82_Arrival_Funky_POKEY.xex`.

## What runs on the Atari

The three `.xex` files contain actual **6502 machine code** that updates the Atari's **POKEY sound registers** (`AUDF1..4 / AUDC1..4` at `$D200..$D207`) while displaying the existing ANTIC E title/intro/arrival artwork. They should run on a stock NTSC **Atari 800XL (64 KB)** in Atari800 or Altirra; no Python, external audio files, or samples are required at runtime. Each track loops in its scene.

The title retains START-key behavior from the prior standalone prototype: pressing **START** mutes music and displays `START PRESSED`, without advancing to the next screen. The cutscene **FIRE TO CONTINUE** prompts are still visual only; integration of scene transitions is future work.

**Validation status:** All XEX segments, patch locations, memory layout, POKEY register patterns and reproducible build hashes have been checked in code. **These specific music-enhanced XEX files have not yet been run in a real Atari emulator or physical Atari by the user.** Test in Atari800 5.2.0 before declaring sound quality or timing final.

## Atari / POKEY design

- Four monophonic voices: 1 melody, 2 harmony, 3 bass, 4 POKEY percussion/noise.
- `AUDCTL = $00`: 64 kHz clock, four separate 8-bit channels; pitch divider `AUDF ~= 63921/(2 * Hz) - 1`.
- Bass is **transposed one octave higher** than the reference MP3 to fit into a single 8-bit 64 kHz channel while retaining all four voices. Pitch-bend flourishes and envelopes of the reference versions are simplified; expect an unmistakably chippier sound.
- Update once per **NTSC Atari OS vertical blank** using the low byte of RTCLOK at `$14`, with a 16-bit fractional tempo accumulator. Each tick is a **16th note**, 192 steps/12 bars for rock and 128 steps/8 bars for funk.
- Runtime music code and eight per-tick register lookup tables are loaded at `$7000`. The screen's prior `RUNAD` `$2000`, graphic memory, DLI palette handling, and original display are retained. No shared engine or real scene advance yet.
- 6502 player is generated by `build_pokey_music.py`; the generated `rock_pokey_6502.asm` and `funk_pokey_6502.asm` are **reference assembly listings**. Do not assume they were built/tested with MAC/65. `build_pokey_music.py` is the verified builder.

## MP3 files: critical distinction

- `01_Arcade_Rock.mp3` and `02_Funky_Gas_Attack.mp3`: the **original POKEY-inspired composition reference MP3s** the music choices were based on, **not** Atari POKEY output.
- `01_Arcade_Rock_POKEY_Approx.mp3` and `02_Funky_Gas_Attack_POKEY_Approx.mp3`: software-generated audio **approximating the register sequences emitted by the actual Atari code**, but still **not an accurate POKEY emulator recording**. Atari POKEY distortion/polynomials and screen PAL/NTSC clock differences can make the XEX sound different. The emulator is the authoritative listening test.

## Rebuild

From this directory (Python 3, `numpy`, and `ffmpeg` installed):

```bash
python build_pokey_music.py
```

Keep `compose_demos.py`, `base_screens/` and `build_pokey_music.py` alongside each other. The builder uses **the original note events** of the chosen compositions, quantizes them to 16th notes, converts to POKEY AUDF/AUDC bytes, builds the 6502 player and patches the original standalone XEXs. The `*_pokey_registers.bin` files are 8 interleaved register bytes per tick in order `$D200`–`$D207`, with a separate song source note dump (`*_pokey_note_events.json`).

The original title-screen source art and its first build script live under `assets/title/` in the repository; crew and arrival art/builds remain in `assets/intro/` and `assets/arrival/`.

## Test instructions

```bash
atari800 -xl -nobasic -run ./GasBlasters82_Title_ArcadeRock_POKEY.xex
atari800 -xl -nobasic -run ./GasBlasters82_MeetTheCrew_Funky_POKEY.xex
atari800 -xl -nobasic -run ./GasBlasters82_Arrival_Funky_POKEY.xex
```

`START` on the title changes the prompt and stops the soundtrack. The two cutscenes continue looping their music until the emulator is stopped/reset.
